# 💻 Portfólio Pessoal

Este repositório contém o desenvolvimento do meu portfólio pessoal, criado como parte das atividades acadêmicas da disciplina de **Front-End para Web**, no curso de Engenharia de Software.

O projeto tem como objetivo apresentar minhas habilidades, conhecimentos, tecnologias estudadas e projetos desenvolvidos, além de aplicar na prática os conceitos de desenvolvimento web.

## 🚀 Tecnologias utilizadas

As seguintes tecnologias foram utilizadas no desenvolvimento:

- **HTML5:** estruturação e organização do conteúdo das páginas.
- **CSS3:** estilização, layout, responsividade e identidade visual.
- **JavaScript:** implementação de funcionalidades e interatividade.

## 🎯 Objetivos do projeto

- Desenvolver uma página pessoal utilizando tecnologias fundamentais do desenvolvimento Front-End.
- Aplicar conceitos de HTML, CSS e JavaScript.
- Criar uma interface intuitiva, organizada e visualmente agradável.
- Apresentar informações profissionais, conhecimentos técnicos e projetos acadêmicos.
- Desenvolver um projeto que possa integrar meu portfólio profissional.

## 🛠️ Funcionalidades

- Apresentação pessoal.
- Exibição de conhecimentos e tecnologias.
- Seção de projetos.
- Layout adaptável a diferentes tamanhos de tela.
- Elementos interativos desenvolvidos com JavaScript.
- Links para contato e redes profissionais.

## ▶️ Como executar o projeto

1. Faça o clone deste repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Acesse a pasta do projeto.
3. Abra o arquivo `index.html` em seu navegador.
4. ou abre o site 🌐 **[Acesse meu Portfólio](https://victordanieldev.github.io/portfolio/)**
